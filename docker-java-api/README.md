# Java Spring Boot API + PostgreSQL (Docker)

Projeto de containerização de uma API Java Spring Boot conectada a um banco de dados PostgreSQL usando Docker e Docker Compose.

## 🛠️ Tecnologias
- Java 17 / Spring Boot
- PostgreSQL 15
- Docker & Docker Compose
- Maven

## 🚀 Como Executar

1. Certifique-se de ter o Docker e Docker Compose instalados.
2. Na raiz desta pasta (`docker-java-api`), execute:
   ```bash
   docker compose up --build
